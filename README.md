# IDA-OS

A free GitHub reconstruction of the IDA desktop web OS.

The original Macaly project remains untouched and is the fallback/reference version.

## Current stage

This repository contains the first IDA shell:
- desktop
- IDA crescent start button
- desktop app icons
- double-click launching
- draggable windows
- minimize/maximize/close
- taskbar
- taskbar minimize/restore/switch behavior
- Start menu
- search shell
- Wi-Fi toggle shell
- mobile taskbar hiding

The full IDA behavior and app implementations will be rebuilt incrementally.

## Publishing

This repository is intended for GitHub Pages. GitHub Pages can publish public repositories on GitHub Free, and GitHub Actions can automatically redeploy after pushes to main.
